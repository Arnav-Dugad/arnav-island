# Future premium features

These are suggestions, not implemented features or promised integrations.

1. **Artwork continuity:** the tiny cover travels into the large media card as one object, retaining velocity if interrupted.
2. **Compact live activities:** volume, timer and current track occupy a tiny useful strip without opening the full dashboard.
3. **File shelf:** drop files into the island, see elegant previews and drag references back out safely.
4. **Quiet charging animation:** a restrained pulse fills a battery shape and settles back into the pill.
5. **Audio route picker:** switch speakers and headphones from a compact, named device list.
6. **Smart brightness:** a smooth brightness slider only appears when the display supports safe control.
7. **Personal dashboard:** reorder a few useful cards instead of filling the island with everything.
8. **Album accents:** extract a muted color from artwork in the background, with strict contrast limits.
9. **Magnetic controls:** very subtle pointer attraction and physically animated press/release feedback.
10. **Acrylic expansion:** a measured native glass layer appears only on expanded surfaces, with a solid fallback.
11. **Focus progress ring:** a thin ring slowly measures the session; completion resolves into a calm breathing shape.
12. **Multi-display profiles:** remembered position, scale and behavior for each physical monitor.
13. **Quick note:** a private, local scratchpad with a clear delete action and no cloud dependency.
14. **Privacy reveal:** sensitive activity text stays concealed until deliberate interaction.
15. **Safe activity timeline:** a small, local history of device, battery and timer events, without capturing private content.
16. **Full accessibility:** proper screen-reader controls, text scaling and excellent keyboard focus movement.
17. **Performance studio:** measured frame pacing, presentation latency and power cost, clearly separated from estimated counters.
18. **Signed releases and safe updates:** verified packages, rollback and release notes, without forced background downloads.
